## What's new

- Addon inventory stays usable with stray files, and metadata reads happen outside
  the client-operation lease.
- The addon backend tolerates malformed records and bounds route durations.
- A proven-closed guest is recovered before an update instead of blocking it.
- The header-only adoption diagnostic from the C218 test build is removed.
- Releases are now built and audited by the self-hosted workflow described in
  `docs/releasing.md`.

## Installation

Install manually over the existing debug-signed preview; no uninstall or data reset
is required. Pause a running download before replacing the APK. Updates remain
manual: this build has no in-app update checker.

## Before you try

- Experimental preview for Android ARM64. No game client is included.
- The build passed `PASS_SOURCE_BUILD_AND_PAYLOAD_AUDIT` (2,233 audited source
  files, 178 payloads), but C219 has not been installed or tested on a device.
  Build evidence is not gameplay, performance or multi-device evidence.
- Download speed, sustained sessions, audio and controller support remain
  unverified for this build.
- The attached source coverage is partial and is not a self-contained build
  environment; the recipe also reads artifacts that are not redistributed here.
- The build is debug-signed with the same certificate as previous previews.
