## What's new

- Adds a dismissible update notice. Opening a release page requires a tap; the app
  does not download or install APKs.
- Corrects the permission configuration for the functional launcher entry; the
  diagnostic components retain their protections.
- **Update checks in this APK no longer work after the repository rename.** The
  former API address now redirects, and C142 rejects redirects. Check this release
  page manually for updates.

## Installation

Install this APK manually over the existing app. Do not uninstall the app or clear
its data as part of this upgrade. There is no reliable automatic update path.

## Before you try

- This is an experimental ARM64 build using the existing Android debug signing; it
  is not a general release.
- C142 has not been installed or visually tested on a physical device. No measured
  performance or sustained-session result is available.
- The game client is proprietary and is not included. The attached source archive
  is partial: it is not complete Corresponding Source for every binary or a
  self-contained build environment.
