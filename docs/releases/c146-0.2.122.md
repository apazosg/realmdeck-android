## What's new

- Home-integrated preparation, explicit download consent, pause/resume and smoothed speed estimates.
- Wi-Fi-only app-managed downloads, verified contiguous archive batches and bounded catalog lookups.
- Compatible checkpoint recovery and up to sixteen authenticated objects per durable commit group, retaining raws until data and checkpoint are forced.
- Approved lighter storage validation for directed sourceless installs: full checks at admission, segment opens and activation; fresh identity checks per durable group. Some marker, ancestor and mount-metadata checks are deferred between those boundaries.
- Ordinary launcher-icon access restored without opening protected diagnostic components.

## Installation

Install manually over the existing debug-signed preview; no uninstall or data reset is required. Pause a running download before replacing the APK. Updates are manual: this preview does not include an APK update checker.

## Before you try

- Android ARM64, experimental debug signing and device-specific runtime/storage requirements apply. No game client is included.
- C146 was audited and installed on one phone; upgrade fingerprints were preserved and ordinary launcher entry was observed. This does not establish full-client completion, sustained gameplay or multi-device compatibility.
- Download trials varied substantially with object cohorts. C143 recorded 3.88 MB/s in one completed window; the later C145 group16 trial recorded 0.40 MB/s. These are not paired A/B measurements or a C146 speed guarantee. The 3.2-MB/s engineering target remains open.
- Known pre-existing resolver/version-guard/UI-wording test failures remain documented; do not interpret focused passing regressions as a fully green repository suite.
- The attached source contains available application/build sources, not complete sources for every bundled runtime binary or a self-contained build environment. See its coverage manifest and component notices.
